重新對應 Nothing 手機的 Essential Key。單擊、雙擊、三擊、長按各自綁定你真正會用的捷徑。

不需要 Root、不需要電腦、不需要 ADB。

Essential Space 可以留著

雙擊、三擊與長按開箱即用,不必停用任何東西,Essential Space 與錄音功能照常運作。只有在你連單擊也想拿回來時,才需要那個選用的解鎖精靈——它會帶你走過 Nothing 官方的應用程式資訊頁面,反悔了也能照樣還原。

每個按法可以做什麼

* 開啟任何已安裝的應用程式
* 切換手電筒
* 擷取螢幕截圖
* 鎖定螢幕
* 播放或暫停、跳到下一首或上一首
* 在響鈴、震動、靜音之間循環

為你手上那顆按鍵而做

引導式設定會讓 App 學會哪一顆才是你的 Essential Key,而不是寫死某個硬體代碼,因此能適應不同機型與韌體更新。按鍵測試畫面會即時顯示 App 收到的事件,你看得到它確實在運作。

沒有廣告、沒有數據分析、沒有追蹤、不需要帳號。完全開源,每一行程式碼都可以在 github.com/KoukeNeko/EssentialKeyTools 讀到。

Essential Key Tools 需要一支具備 Essential Key 的 Nothing 手機,並執行 Android 15 或以上版本。

為什麼這個 App 需要無障礙權限

Essential Key Tools 只會使用 Android 的無障礙服務 API 來偵測 Essential Key 的按壓(即使 App 沒有開啟),並執行你所選擇的捷徑。啟用後,它會接收到哪一個實體按鍵被按下或放開、以及發生的時間,藉此分辨單擊、雙擊、三擊或長按。

按鍵資訊只會在裝置上即時處理,硬體按鍵事件不會儲存、上傳或分享。你設定的捷徑與確認的 Essential Key 識別碼只會儲存在裝置上。App 不會讀取螢幕內容、文字欄位或你輸入的文字。「螢幕截圖」與「鎖定螢幕」也只會在你把它們設成捷徑時執行。

你可以在設定過程中自行決定是否使用輔助功能;選擇不使用不會啟用服務。

當機報告

若 App 發生當機,會在你的裝置上寫入一份診斷報告,方便你回報問題。報告包含 App 版本、機型、Android 版本與技術錯誤細節,不含輔助功能服務所觀察到的任何內容,不會自動上傳,你也可以隨時分享或刪除。
