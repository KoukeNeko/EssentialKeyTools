## New features & improvements

📳 Added haptic feedback: the phone can now vibrate each time you press the Essential Key, with Off / Light / Medium / Strong options on the home screen. It's off by default. Requested in [#4](https://github.com/KoukeNeko/EssentialKeyTools/issues/4).

## Bug fixes

🔒 Fixed the first Essential Key press doing nothing after the screen had been off for a few seconds. Nothing OS uses that press to wake the screen, and the app now recognises it and runs the assigned action. Reported in [#5](https://github.com/KoukeNeko/EssentialKeyTools/issues/5).
