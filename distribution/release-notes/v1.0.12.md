## New features & improvements

⏭️ Skip what you are listening to with the new Next track and Previous track actions. Assign either one to any press pattern. Requested in [#1](https://github.com/KoukeNeko/EssentialKeyTools/issues/1).

🩺 New Diagnostics screen shows the last crash the app caught, plus the process exits Android recorded. Open it from Setup on the home screen.

📋 Report on GitHub opens a prefilled issue and copies the full report, so reporting a crash is a paste rather than a transcription.

🔕 Added a shortcut to Do Not Disturb access, which the ringer cycle needs before it can reach silent mode.

## Bug fixes

🔔 Fixed a crash when the ringer cycle ran while the phone was already silent.

🖼️ Fixed a crash in the action picker caused by an installed app with an oversized launcher icon.

## Privacy

🔒 Crash reports stay on your device and are never transmitted. There is no crash-reporting service and no server behind the app. A report contains nothing the accessibility service observes — no screen content, no notification text, and no record of which keys you pressed.

📱 Verified on a Nothing Phone (3) before release.
