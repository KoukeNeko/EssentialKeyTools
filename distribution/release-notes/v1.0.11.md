## What's changed

- Added **Next track** and **Previous track** actions, so a gesture can skip through what you are
  listening to without unlocking the phone. Requested in [#1](https://github.com/KoukeNeko/EssentialKeyTools/issues/1).
- Added a **Diagnostics** screen showing the last crash the app caught, alongside the process exits
  Android itself recorded. Its **Report on GitHub** button opens a prefilled issue and copies the
  full report, so reporting a crash is a paste rather than a transcription.
- Fixed a crash when the ringer-cycle action ran while the phone was already silent, where the
  fallback path retried a change the platform had just refused.
- Fixed a crash in the action picker when an installed app reported an oversized launcher icon.
- Added a shortcut to the system Do Not Disturb access screen, which the ringer cycle needs before
  it can reach silent mode.

## Privacy

Crash reports are written to the app's private storage on your device and are never transmitted.
There is no crash-reporting service and no server to send them to. A report leaves your device only
if you copy or share it yourself, and it deliberately contains nothing the accessibility service
observes — no screen content, no notification text, and no record of which keys you pressed.
